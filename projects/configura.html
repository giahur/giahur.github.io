Configura

Character creator creation plugin

Godot GDScript
Role: Developer
Team Size: 4 people
Duration: 3 months

Flexible framework for building character creators. Allows developers to upload their own 3D model, parses through the options, then creates a character creator scene. Supports modular assets, mesh deformation, skeletal deformation, and materials.

Shop Documentation

Responsibilities

Developer

  • Familiarized self with existing codebase.
  • Consistently updated documentation throughout project to help users.
  • Overhauled existing UI for plugin dock to be more readable and more consistent with Godot inspector.
  • Researched and implemented bone deformation feature, allowing users to deform their model's skeleton through code.
  • Combed through entire codebase cleaning up code to follow good coding conventions, ensuring better team collaaboration and improving code readability.
  • Submitted reviews, approved pull requests, and merged branches on GitHub.
  • Delivered a complete, viable product, published to the Godot Asset Store.

Process

Configura began as "Figura", a website for artists to customize and pose 3D models for references when figure drawing. The project was built by Audrey Fuller as her Computer Science Master's capstone project. In the process of creating this tool, she discovered that there were little to no tools that helped game developers create character creators based on a custom 3D model. The project pivoted to provide this workflow between artist and developer. In conversations with MAGIC Spell Studios, she was recommended to apply for the Traver Creative Technologist Program. This program is a funded entrepreneurism residency focused on technology solutions for creative industries, especially those that make multidisciplinary connections across technology, art, and business. This opened up the project to be further developed by our summer team.

Over the summer, we used an Agile software prototyping process. During our first milestone, we focused on familiarizing ourselves with the codebase and taking note of what could be improved upon. Including meetings with the program's namesake John Traver, an RIT alumnus and creator of frame.io. In all, we delivered a viable product.
